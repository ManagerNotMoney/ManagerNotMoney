### 🧔 Обо мне

Я **Менеджер Денег**, разработчик из Санкт-Петербурга. Пишу самописные плагины для **Minecraft** (версия 1.21.11) на серверном ядре **Paper**.

Моя цель — создавать уникальные механики, которые делают игру интереснее, сложнее и атмосфернее. Специализируюсь на:
- 🧩 Создании сложных систем с нуля (крафты, экономика, GUI).
- 🌿 Разработке аддонов, расширяющих функционал моих же плагинов.
