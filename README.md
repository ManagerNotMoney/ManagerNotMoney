## 🧔 Обо мне

Пишу самописные плагины для **Minecraft** (Paper 1.21+) на Java и браузерные игры на чистом JavaScript. Специализируюсь на нестандартных механиках с нуля: крафты, экономика, кастомные GUI, процедурная генерация. Каждый проект — часть единой экосистемы.
